About the System

Employee Management System

A practical Flask and MySQL application for secure employee administration.

What is this application?

The Employee Management System is a Flask and MySQL based web application designed to manage employee records. Admin and HR users can authenticate securely and perform CRUD operations on employee information.

Database tables are initialized automatically by Flask using mysql.connector, so no separate SQL setup file is required.

Technology Stack

Python Flask MySQL mysql.connector Jinja2 HTML5 CSS3 Bootstrap 5

Admin Authentication

Password hashing, credential verification, session management, and protected administrative routes.

CRUD Operations

Create, read, update, and delete employee records using parameterized MySQL queries.

Session Management

Flask sessions control authentication state and dynamically change the navigation experience.
